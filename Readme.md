# ✊ Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using HTML, CSS, and JavaScript. Play against the computer, test your luck, and see who wins!

## 🎮 Features

- 🪨 Choose Rock, Paper, or Scissors.
- 🤖 Computer generates a random choice.
- 🏆 Automatically determines the winner.
- 📊 Displays game results and scores (if implemented).
- 🎨 Clean and user-friendly interface.
- 📱 Responsive design (if implemented).

## 🛠️ Technologies Used

- **HTML5** – Structures the game interface.
- **CSS3** – Styles the page and game elements.
- **JavaScript** – Implements game logic and interactivity.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/naveendhegde2006-cmd/rock-paper-scissors.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Choose Rock, Paper, or Scissors and play against the computer!

## 📜 Game Rules

- **Rock** beats Scissors.
- **Paper** beats Rock.
- **Scissors** beats Paper.
- If both players choose the same option, the game is a draw.
